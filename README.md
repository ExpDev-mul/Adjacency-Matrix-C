# 📊 Adjacency Matrix Path Checker (C)

A C program that reads an **adjacency matrix** and provides feedback on the absence or presence of a path between a pair of vertices in a graph.

## 🔧 Features

- Reads an adjacency matrix input
- Checks if there’s a path between two vertices
- Provides feedback on the connection status

## 🛠️ Requirements

- C Compiler (e.g., GCC)
- Make (for building)

## 🧑‍💻 Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/ExpDev-mul/Adjacency-Matrix-C.git
   cd Adjacency-Matrix-C/adjacency
   ```

2. Compile the program:
   ```bash
   make
   ```

3. Run the program:
   ```bash
   ./path_checker
   ```

4. Input the adjacency matrix when prompted and specify the vertices to check for a path.

## 📌 Notes

The program uses a basic graph traversal technique to determine path existence between vertices.
